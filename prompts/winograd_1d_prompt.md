【2. 固定顶层接口】

模块名必须为 `winograd_1d`，使用 ANSI 风格端口声明，名称、方向、位宽不得改变。

| 端口 | 方向 | 类型/位宽 | 含义 |
|---|---|---|---|
| clk | input | logic | 单一时钟，上升沿采样 |
| rstn | input | logic | 低有效复位 |
| en | input | logic | 当前输入组有效 |
| r1_x, r2_x, r3_x, r4_x | input | logic signed [31:0] | 四个输入数据 |
| r1_w, r2_w, r3_w | input | logic signed [31:0] | 三个卷积核权重 |
| r1_res, r2_res | output | logic signed [31:0] | 两个寄存器输出结果 |
| vld | output | logic | 与输出结果同拍的寄存有效标志 |

所有输入数据及权重均覆盖完整 32 位有符号范围。每组输入自带权重，不能假设权重固定。没有 ready、busy、start 或反压协议，不能自行增加端口。

【3. 功能与结果语义】

令 d0..d3 对应 r1_x..r4_x，g0..g2 对应 r1_w..r3_w。参考结果为：

```text
y0 = d0*g0 + d1*g1 + d2*g2
y1 = d1*g0 + d2*g1 + d3*g2
r1_res = y0 的低 32 位
r2_res = y1 的低 32 位
```

按二进制补码取低 32 位，允许最终回绕；不饱和、不舍入，结果必须逐位一致。禁止用直接卷积的六次乘法替代 Winograd。

采用以下统一放大权重两倍的整数变换，避免提前除以 2 丢失精度：

```text
t0 = d0 - d2        u0 = 2*g0
t1 = d1 + d2        u1 = g0 + g1 + g2
t2 = d2 - d1        u2 = g0 - g1 + g2
t3 = d1 - d3        u3 = 2*g2

p0 = t0*u0
p1 = t1*u1
p2 = t2*u2
p3 = t3*u3

s0 = p0 + p1 + p2
s1 = p1 - p2 - p3
y0 = s0 >>> 1
y1 = s1 >>> 1
```

数据通路仅包含上述四个一般乘法运算。乘以 2 使用加法或左移。给出代数核对，说明 s0、s1 分别等于参考卷积结果的两倍，低位必为 0，因此最后的算术右移不会丢失有效信息。

【4. 位宽与符号约束】

采用下表的保守位宽，不自行缩窄：

| 信号 | signed 位宽 | 要求 |
|---|---|---|
| d、g | 32 | 原始输入 |
| t0..t3 | 33 | d 先符号扩展至 33 位，再加减 |
| u0..u3 | 34 | g 先符号扩展至 34 位，再加减或左移 |
| p0..p3 | 67 | 保留 33×34 位完整乘积 |
| s0、s1、右移结果 | 69 | p 先符号扩展至 69 位，再加减、算术右移 |
| r1_res、r2_res | 32 | 最后显式取右移结果 [31:0] |

- 加减、移位前扩展；不得先在 32 位中溢出后再赋给宽信号。
- 显式保证乘法表达式完整保留 67 位；不能仅凭左侧信号较宽就认定所有子表达式安全。
- 拼接和切片可能改变 signed 属性，运算前使用 signed 临时信号或显式转换；禁止意外的有符号/无符号混算。
- `>>>` 的左操作数必须为 signed；常量显式标注位宽与符号，避免无位宽整数参与数据运算。
- 仅最终截取低 32 位，添加“有意截断，按模 2^32 输出”的注释。不得提前截断 p 或 s。
- 验证参考模型也必须足够宽，不能用单个 64 位 longint 累加三个全范围 32×32 位乘积。

【5. 逐拍时序：以边沿定义为准】

一个输入组在 en=1 的上升沿 E0 被接受。E0 算第一个边沿，E2 算第三个边沿；在 E2 的非阻塞赋值更新完成后，输出该组结果且 vld=1。E0 到 E2 相隔两个时钟周期，不得因为“三拍”措辞多增加一级输出寄存器。

| 上升沿 | 第一级 | 第二级 | 第三级/输出 |
|---|---|---|---|
| E0 | 锁存输入组 A 的 t、u | 处理更早输入 | 处理更早输入 |
| E1 | 可接受输入组 B | 锁存 A 的 p0..p3 | 处理更早输入 |
| E2 | 可接受输入组 C | 处理 B | 锁存 A 的输出并给出 vld |

- 第一级：输入变换和权重变换并行；第二级：四个乘法并行；第三级：输出变换、右移和最终截位。
- 每个上升沿都可接受一组输入，吞吐率为每周期一组。
- en=0 表示插入无效气泡，不是暂停整条流水线；前面已接受的输入仍须按时到达输出。
- 有效位每拍移位，行为等价于：`valid_s1 <= en; valid_s2 <= valid_s1; vld <= valid_s2;`。这些赋值在同一边沿读取旧值。
- 输出数据更新由更新前的 valid_s2 控制，不能读取该边沿刚赋值的 vld 来判断。
- vld=0 时输出数据寄存器保持上一值，vld 本身继续正常更新，不得粘连为 1。
- 既有 testbench 时钟周期 10ns：首组输入 20ns 驱动、25ns 采样，应在 45ns 上升沿后有效，46ns 检查。用这一例子核对流水线深度。

【6. 复位和编码规范】

以下属于本次实现的明确选择：rstn 异步拉低复位，使用 `always_ff @(posedge clk or negedge rstn)`；测试环境在非上升沿释放复位，不在模块内增加复位同步器和额外启动延迟。

- 复位优先于正常操作，清零所有流水寄存器、输出和有效位；复位清空在途事务，不允许旧结果在复位后重新出现。
- 时序块使用 always_ff 和非阻塞赋值；组合过程使用 always_comb 和阻塞赋值，所有组合输出完整赋值。简单组合连接允许 assign。
- 每个信号仅由一个过程或驱动源赋值；禁止 latch、门控时钟、RTL 中的 initial、# 延迟、等待事件及不可综合系统任务。
- 子模块按名称连接端口；不增加无关状态机，不做接口参数化扩展。

【7. 时序分析的输出要求】

请给出可核对的结构分析，而不是声称物理时序已通过：

1. 画出三级寄存边界，列出各级寄存器保存的数据和 valid。
2. 用 en 序列 `1,1,0,1,0,0` 列出复位后连续六个边沿更新完成后的 vld，预期为 `0,0,1,1,0,1`；标明每个有效输出对应哪组输入。
3. 说明连续输入、气泡和中途复位如何传播，检查数据与 valid 是否错位。
4. 列出组合路径候选：第一级加减，第二级乘法，第三级宽位加减及移位/截位。区分输入到寄存器、寄存器到寄存器、寄存器到输出路径。
5. 说明最后一级加减的逻辑深度；常数移位和切片通常可化为布线。没有目标工艺、综合和 STA 报告，不得断言哪一级一定最慢或已经达到 100MHz。10ns 是当前功能仿真的时钟周期。
