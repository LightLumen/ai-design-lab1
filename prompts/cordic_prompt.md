【2. 固定接口：名称与顺序均不可变】

原 testbench 使用位置例化 `cordic TEST_RUN(clk, Xin, Yin, angle, COSout, SINout, done)`，因此以下端口顺序必须严格保持。

| 顺序 | 端口 | 方向 | 类型/位宽 | 说明 |
|---|---|---|---|---|
| 1 | clk | input | logic | 单时钟，上升沿采样 |
| 2 | Xin | input | logic signed [15:0] | 初始向量 x，16 位补码 |
| 3 | Yin | input | logic signed [15:0] | 初始向量 y，16 位补码 |
| 4 | angle | input | logic [31:0] | 无符号整圈角度编码 |
| 5 | COSout | output | logic signed [15:0] | 旋转后的 x 分量，寄存输出 |
| 6 | SINout | output | logic signed [15:0] | 旋转后的 y 分量，寄存输出 |
| 7 | done | output | logic | 流水线填满后的输出可用标志 |

testbench 将 Xin、Yin 声明为无符号 reg，但它们的位模式在 DUT 内按 signed 解释。

没有复位、en、start、ready 或 busy，不得增加端口。每个上升沿接受一个完整的 Xin/Yin/angle 组合，不依赖角度是否改变，也不能假设权重式固定输入或只支持第一象限。

【3. 功能、角度编码与增益】

角度使用 BAM 整圈编码：`theta = angle * 2*pi / 2^32`，不是整数度数，也不是弧度定点数。

```text
0°   = 32'h00000000
90°  = 32'h40000000
180° = 32'h80000000
270° = 32'hc0000000
45°  = 32'h20000000
```

旋转模式 CORDIC 的目标为：

```text
G16 = product(i=0..15, sqrt(1+2^(-2*i))) ≈ 1.646760258
Xout ≈ G16 * (Xin*cos(theta) - Yin*sin(theta))
Yout ≈ G16 * (Xin*sin(theta) + Yin*cos(theta))
```

公开 testbench 采用 `Xin = 32000/1.64676`、`Yin=0`，实际 16 位赋值约为 19432，已经在输入端补偿增益。因此期望 `COSout≈32000*cos(theta)`、`SINout≈32000*sin(theta)`。不要在 RTL 中再次乘 1/G16；也不要用直接乘以 sin/cos 的方式替代 CORDIC。

结果不饱和。对于超出 16 位范围的一般输入向量，先完成内部计算和小数移除，再按低 16 位补码回绕。数值误差测试应使用输出在可表示范围内的向量；回绕情形另按明确的量化及模 2^16 语义检查。

【4. 先归约象限，再做 16 次迭代】

采用 N=16，i=0..15。预处理将目标角度归约到 [-90°,90°)；必须同时处理向量，不能只修改残余角度。

```text
若 0x40000000 <= angle < 0xc0000000：
    x0 = -Xin_fixed; y0 = -Yin_fixed
    z0 = unsigned_extend33(angle) - 33'h080000000
否则若 angle >= 0xc0000000：
    x0 = Xin_fixed; y0 = Yin_fixed
    z0 = signed({1'b1, angle})  // 等价于 angle - 2^32
否则：
    x0 = Xin_fixed; y0 = Yin_fixed
    z0 = unsigned_extend33(angle)
```

所有 z 的运算按 signed 33 位执行；半圈常量 2^31 必须显式声明为 signed 33 位正数，不能依赖无符号混算。注意：signed 33 位不能表示正的 2^32，禁止将 33'sh100000000 错当正整圈常量。末象限使用上述显式符号扩展实现 angle-2^32；若坚持做减法，则使用至少 signed 34 位中间结果，并证明收窄安全。其他分支先把 angle 零扩展到 33 位并存入 signed 临时信号，不能把整个 32 位 angle 直接当成负角后仍套用上述区间判断。

对各 i：

```text
Ai = round(atan(2^-i) * 2^32 / (2*pi))
若 zi >= 0：
    x(i+1) = xi - (yi >>> i)
    y(i+1) = yi + (xi >>> i)
    z(i+1) = zi - Ai
否则：
    x(i+1) = xi + (yi >>> i)
    y(i+1) = yi - (xi >>> i)
    z(i+1) = zi + Ai
```

同一轮 x/y/z 均使用本轮旧值，不允许先更新 x 再用新 x 更新 y。列出全部 16 个常量的十六进制值，并检查第一项 `A0=32'h20000000`。角度常量以 signed 33 位正数存储，符号扩展及与 z 的单位保持一致。

【5. 位宽与量化约束】

| 信号 | 格式 | 规则 |
|---|---|---|
| Xin、Yin | signed 16 位整数 | 原始补码输入 |
| 内部 xi、yi | signed 32 位，12 个小数位 | 真实值=寄存整数/2^12 |
| 输入定点化 | signed 32 位 | 先符号扩展到 32 位，再左移 12 位 |
| zi、Ai | signed 33 位 BAM | 不与 x/y 的小数格式混用 |
| 最终去小数结果 | signed 32 位 | 对最后迭代结果做 >>>12 |
| COSout、SINout | signed 16 位 | 最后显式取 [15:0] |

- 最小负数必须先扩展再取负，禁止在 16 位中对 -32768 取负。
- 每次 x/y 加减和算术右移都在 signed 32 位域进行，不逐级缩成 16 位。迭代移位有固定量化误差，须与最终输出截位分开说明。
- 给出范围核对：任意 16 位向量的初始模长不超过 sqrt(2)*32768，乘 CORDIC 增益后约为 76313；乘 2^12 仍有足够的 signed 32 位余量，并考虑量化误差。
- 去除小数选择算术右移，即负值向负无穷方向取整，不自行增加不明确的正负舍入规则；分析对公开测试误差界的影响。
- 有意移除小数及低 16 位截断均写注释。拼接/切片后需重新明确 signed 属性；常量注明位宽和符号。
- 在 testbench 或离线脚本中生成 atan 常量与浮点参考是允许的；RTL 不得出现 real、$sin、$cos、$atan、运行时乘除或其他不可综合数学计算。

【6. 流水线和 done：按具体边沿核对】

采用全展开流水线，所有级每拍前进，不使用共享迭代器或输入变化检测。

| 边沿 | 对某组输入 A 的动作 |
|---|---|
| E0 | 接受 A，寄存象限归约后的 x0/y0/z0 |
| E1 | 完成 i=0，寄存 x1/y1/z1 |
| E2 | 完成 i=1，寄存 x2/y2/z2 |
| … | … |
| E15 | 完成 i=14，寄存 x15/y15/z15 |
| E16 | 完成 i=15，去小数并更新 A 的 COSout/SINout |

E0→E16 相隔 16 个周期，共 17 个边沿位置。输出寄存器就是最后一次迭代的寄存边界，不能先寄存 x16/y16，再多加一个 E17 输出级。吞吐率每周期一组，数据和角度必须作为同一个事务经过所有级。

公开 testbench：时钟周期 4ns，上升沿在 2+4k ns。角度在 1000ns 改变，1002ns 为 E0；1066ns 为 E16，应在该边沿后得到对应结果，早于 1070ns 的原测试检查。用这个具体时间例子核对深度，不能只说“延迟 16 拍”。

本次选择 done 为流水线填满后的连续有效指示：稳定运行后每拍都有输出，done 持续为 1，不是每次角度变化后产生一个完成脉冲。

接口没有复位，不能承诺上电首拍寄存器或 done 为 0，也不能用 initial、声明初始化或检测 X 的技巧制造硬件启动状态。可使用随各级传播的常数 1 标志，使经过完整流水线后 done 已知为 1；填满前的数据和 done 无有效性保证，验证必须明确忽略该预热窗口。不要把这一接口包装成带可靠启动握手的协议。

【7. 编码和时序分析】

- ANSI 端口；logic 与明确 signed 声明；always_ff 只用非阻塞赋值。
- 组合过程使用 always_comb 和阻塞赋值，所有输出在所有路径赋值；简单完整组合表达式允许 assign。
- 每个寄存器只有一个驱动源；静态 generate 展开、命名生成块、移位次数为各级常量；RTL 不含 latch、门控时钟、initial、# 延迟或等待事件。
- 给出寄存边界图，说明归约级、每个微旋转级和最终输出级的路径。每级旋转包括方向判断、常量移位和加减；常量移位通常可化为布线，不是一个运行时通用移位器。
- 分开讨论输入到寄存器、寄存器到寄存器、寄存器到输出路径，包含选择逻辑和最终定点转换。
- 没有目标工艺和 STA 报告，不得宣称达到 250MHz。4ns 仅是当前 testbench 的功能时钟周期。本次不扩展到安装综合/形式工具或执行物理设计。
