【2. 硬性任务与协议】

- 一轮任务包含 tile 0、1、2；加载与计算各按 0→1→2 顺序发出，每个 tile 恰好一次。
- tile n 固定使用 buffer n%2，即 0→0、1→1、2→0。
- 每种引擎最多一个在途操作。请求发出后，等待对应完成脉冲，不能假设固定延迟。
- 请求输出为完整一周期脉冲，相邻周期不能持续为 1；tile/buffer 在请求有效周期必须正确。无 ready，不能等响应前持续拉高请求。
- 响应不会与该请求在同一接收周期出现；最早下一周期。外部引擎在上升沿观察请求，下降沿驱动后续完成脉冲，上升沿由控制器采样。
- 只有对应加载完成后，才能请求计算某个 tile。
- 只允许不同缓冲区的加载与计算重叠；禁止覆盖正在加载、等待计算或正在计算的缓冲区。
- buffer0 必须等 tile0 的 compute_done 后才能给 tile2 复用；load_done 不能替代缓冲释放。
- 必须产生真实的加载/计算重叠，不能把全部操作串行化。
- busy 从接受 start 后保持有效，直至 tile2 的计算完成。done 不能在 tile2 的请求发出时提前产生。

【3. 明确的实现选择】

- rstn 异步低有效，复位清除请求、done、busy、计数器、在途和占用信息；复位丢弃在途任务，复位期间不发请求。
- start 在 IDLE 中按电平采样；RUN 中的 start 忽略且不排队。若一直保持 start=1，回到空闲后可开始下一轮；不添加上升沿检测协议。
- done 与最后完成脉冲被控制器采样的边沿对齐，在该边沿 NBA 后高一周期，busy 降为 0。下一上升沿若空闲且 start=1，可接受新一轮。
- 无对应在途操作的孤立完成脉冲忽略，不能推进计数器或制造 done。
- 复位后无请求时的旧完成脉冲可被忽略；接口没有事务 ID，不能保证区分新请求在途时到来的旧响应。环境必须同时取消/清空旧引擎事务，不能声称控制器独自解决此问题。
- 请求无效时 tile/buffer 输出保持上一值，复位时为零。

【4. 状态与资源记录】

采用 enum 主状态 IDLE/RUN，配合独立 load_active、compute_active、两位 full、两位 next_load/next_compute 计数。主状态不是全部状态：必须解释资源标志如何共同区分 EMPTY、LOADING、READY、COMPUTING。

next_load/next_compute 范围 0..3，3 表示已全部发出，不能当成有效 tile 或回绕到 0。各操作记录其 buffer/tile；可利用在途期间保持的已寄存元数据。一个 buffer 从加载请求开始被占用，在加载完成后可计算，直到计算完成才真正释放。

建议主流程：

```text
IDLE + start -> 清空本轮记录，发出 load tile0/buf0，进入 RUN
RUN + 对应 load_done -> 标记该 buffer 已加载
RUN + 对应 compute_done -> 释放该 buffer
RUN + 有空闲加载引擎与可用目标 buffer -> 发下一个 load_req
RUN + 有空闲计算引擎且目标 tile 加载完 -> 发下一个 compute_req
RUN + tile2 的 compute_done -> done=1，返回 IDLE
```

完成事件先更新下一状态，再依据更新后的可用资源调度，允许同一边沿发出不同 buffer 的加载/计算请求。确保先后调度的两条逻辑看到一致的资源预留，不能同抢一个 buffer。

【5. 时序分析必须覆盖】

1. start 接受、请求在 NBA 后出现、引擎下一上升沿接收、done 下降沿驱动及控制器下一上升沿采样，分清观察位置。
2. 典型重叠：L0→(C0与L1并行)→(L2与C1并行)→C2；第二段并行需等待相应实际完成事件，不能写死周期。
3. 加载快、计算快、相等延迟、最短一周期延迟以及同拍 load_done/compute_done。
4. 同拍完成与新请求能否交接、请求是否满足一周期脉冲、busy/start 优先级、最终 done 是否与最后完成一致。
5. 异步复位会中断任务，复位后能重新开始；零等待多轮重启不泄漏上一轮 full/计数器。
6. 同缓冲冲突、未加载先计算、计数器回绕、并行完成覆盖更新、busy 过早下降等风险。

【6. 编码与物理时序范围】

使用 always_ff 加非阻塞赋值保存寄存器，always_comb 加阻塞赋值生成下一状态。组合块完整默认赋值，case 有 default，每个信号单一驱动；禁止 latch、RTL initial、延迟、门控时钟及仿真专用语句。

计数和比较使用显式两位无符号常量，只有 next<3 时允许加一。布尔与缓冲编号不引入 signed 混算。

列出寄存器→组合调度→寄存器以及 done/start 输入到下一状态的路径。10ns 是功能测试时钟周期；没有综合和 STA，不宣称达到 100MHz或面积指标，不安装新工具扩大范围。
